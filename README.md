# Learning2Test - Find The Bugs
Dit is een oefening om unit-testen te leren schrijven. Het is een klein programma om vakantiebestemmingen te zoeken als medewerker van een reisbureau en bestemmingen vast te leggen voor klanten.

IN DEZE VERSIE ZITTEN BEWUST EEN AANTAL FOUTEN INGEBOUWD. Vervang alleen het hoofdproject (Learning2Test) van de vorige versie met deze versie. 
OF vervang het testproject (Learning2Test.Tests) die je aangevuld hebt met de basis zoals deze hier gegeven is.

Doel:
* Zoveel mogelijk fouten gevonden hebben, zonder de testset aan te passen
Vind jouw testset alle fouten (zonder aanpassingen aan de testset!!)? Zo niet: Welke fouten heb je over het hoofd gezien?
