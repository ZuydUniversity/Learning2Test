# Learning2Test - Werkende Versie
Dit is een oefening om unit-testen te leren schrijven. Het is een klein programma om vakantiebestemmingen te zoeken als medewerker van een reisbureau en bestemmingen vast te leggen.

IN DEZE VERSIE ZITTEN GEEN FOUTEN. Het doel is om op basis van deze versie testen te schrijven (die allemaal slagen). Als je denkt alles adgedekt te hebben, kun je de 'Find-the-bugs'-versie opstarten, je test-project eraan toevoegen en de testen runnen.

Doel:
* Zoveel mogelijk fouten gevonden hebben, zonder de testset aan te passen.

Vind jouw testset alle fouten (zonder aanpassingen aan de testset!!)? Zo niet: Welke fouten heb je over het hoofd gezien?
